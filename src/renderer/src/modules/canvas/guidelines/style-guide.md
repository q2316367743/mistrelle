# 视觉风格指南（反 AI 俗套铁律）

> 平面设计作品（海报 / 封面 / 配图）的视觉原则。目标是"高级、非模板化"，避免一眼 AI 的俗套感。
> 本文是 canvas_guidelines 的 style-guide 主题，做任何设计前都应遵守。
> **完整风格目录**见 `canvas_guidelines("styles")`（内置预设的签名手法 / 别名 / 画幅），不要在本文件抄写风格全文。

## 0. 风格协商（开工前）

- **会话已锁定设计风格**：以注入的「设计风格」段落为准（含签名手法），必须落地 signature，禁止只换色板。
- **用户指定了风格名 / 别名**：先 `canvas_guidelines("styles")` 对号入座，照抄该条签名手法与配色角色。
- **用户没指定**：不要默认套 Bento / Apple；按内容气质从目录挑 **3~4 个**报出让用户选（目录文末有推荐话术）。用户说「你看着办」再自定一套并贯彻到底。
- **库外风格**（「像 A24」「莫兰迪品牌色」）用四步法拆成可执行规则后再画：
  1. 取 4 个色：底色 / 主文字 / 次要文字 / 一个重音色（超过 5 个说明没看准）
  2. 定字体反差：衬线 vs 等宽、900 vs 300、全大写宽字距 vs 常规
  3. 找签名手法：独有的那一招（一条线 / 一种错位 / 一个形状）；找不到就别动手
  4. 定留白档：35% / 55% / 70% 三选一
- **铁律**：签名手法必须做出来；只换 `$token` 色板不算换风格。
- **强调色整张图只出现一次**（出现第二次就不再是强调色）。

## 1. 设计基调（默认值）

- **创意离散度**：8/10（1=绝对对称，10=艺术性无序）
- **视觉密度**：4/10（1=美术馆留白，10=信息轰炸）
- 默认按此基调执行，除非用户明确要求更保守 / 更夸张，或已锁定风格另有规定。

## 2. 排版铁律

- **禁用 Inter** 做"高级感"标题。优先 `Geist`、`Outfit`、`Cabinet Grotesk`、`Satoshi`、`Noto Sans SC`、`思源宋体` 等更有性格的字形（先
  `font_list`）。
- **层级靠字重 / 颜色 / 间距，不靠无脑放大字号**。大标题字距收紧（letterSpacing 为负或小值）。
- 衬线字体只用于创意 / 文艺 / 编辑风（电影海报、书籍封面、杂志）， **绝不用在科技感的极简作品里**（用无衬线 + 等宽组合）。
- 正文行宽建议 ≤ 60 字符，行高 1.4~1.6；中文见 typography 指南。

## 3. 色彩铁律

- **最多 1 个强调色**，且 **只出现一次**；饱和度 < 80%。
- **禁"AI 紫 / 蓝"审美**：不要紫色按钮辉光、不要霓虹渐变。用绝对中性的基座（Zinc/Slate/米白）+ 单一高对比强调色（翡翠绿 /
  电蓝 / 深玫瑰）。
- **全页只用一套色板**，不混冷暖灰。
- **禁纯黑 `#000000`**，用 off-black / #18181B 等。
- 强调色去饱和，融入中性色。

## 4. 构图铁律

- **禁居中万能构图**（创意离散度 > 4 时）：强制"左右分屏 / 左文右图 / 不对称留白"。
- 视觉节奏：文字多的区块后接视觉强的区块，交替，避免连续堆叠文字段。
- 页面内容限宽（如 ~1400px）防拉伸。

## 5. 材质、阴影与表面处理

- **卡片仅在需要表达层级时用**；阴影颜色 **染成背景色调**更自然，不要死黑。
- 毛玻璃：加 1px 内边框（白色 10% 透明）+ 轻微内阴影，模拟物理折射（锁定「玻璃拟态」风格时按其 signature）。
- **禁霓虹 / 外发光**（「霓虹赛博」风格除外，按其签名手法的多层递进发光）。

## 6. 禁用的 AI 俗套清单

- ❌ 霓虹 / 外发光（非 neon 风格）
- ❌ 纯黑 `#000000`
- ❌ 过饱和强调色；强调色出现两次以上
- ❌ 大标题渐变文字（克制，标题渐变只在小面积用）
- ❌ 用 Inter
- ❌ 无脑超大 H1
- ❌ 三个等宽卡片横排（用之字 / 不对称 / 横向滚动替代）
- ❌ 通用名 "John Doe / 张三"、"Sarah Chan" —— 用有真实感的命名
- ❌ 假数字 "99.99%" / "50%" —— 用有质感的有机数据 "47.2%"
- ❌ 烂大街品牌名 "Acme / Nexus / SmartFlow"
- ❌ 空话 "Elevate / Seamless / Unleash / 赋能 / 助力" —— 用具体动词
- ❌ 随手编一个图片 URL —— 真实素材用 website_logo / image web；无真实来源才用占位
- ❌ 只换色板却声称换了风格（签名手法没做）

## 7. 创意武器库（不要默认套路）

**Hero / 主视觉**

- 文字靠一侧，背景用高质量的图并渐隐融入底色，而不是居中压字。

**布局**

- Bento Grid（苹果控制中心式不对称瓦片）——仅当气质匹配时用，不是默认
- Masonry 瀑布流
- 分割屏滚动（左右对半）

**卡片 / 容器**

- 玻璃拟态面板（真毛玻璃 + 内折射）
- 全息箔卡片（彩虹反光）

**字体**

- 大字走马灯（kinetic marquee 文字带）
- 描边文字 + 渐变描边动画
- 环绕文字路径

**微交互 / 质感**

- 网格渐变背景（有机熔岩色块）
- 噪点颗粒纹理（用 SVG feTurbulence）
- 景深模糊（前景清晰 / 背景虚化）

## 8. Bento Grid 范式（现代 SaaS 感时用）

- 底色浅灰 ~#f9fafb，卡片纯白 + 1px 细边框，大圆角 ~2.5rem，轻扩散阴影。
- 字体用 Geist / Satoshi 系，标题字距收紧。
- 卡片内 32~40px 大留白。
- 排布：行1 三列 | 行2 两列（70/30）。
