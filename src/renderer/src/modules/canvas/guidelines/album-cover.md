# 专辑封面设计指南（album-cover）

> 专辑 / EP / 单曲封面。封面是音乐的一次"视觉转译"：把情绪、风格、概念变成一张图。
> 方形构图的特殊性 + 概念的独特性，是专辑封面的核心。

## 1. 画布尺寸

| 类型 | 比例 | 尺寸 |
|---|---|---|
| 标准专辑封面 | 1:1 | 1000 × 1000 |
| 黑胶封面（加出血） | 1:1 | 1400 × 1400 |
| 方形缩略图友好 | 1:1 | 建议 1000~1400 |

## 2. 概念先行

- 先明确音乐的气质：电子 / 摇滚 / 民谣 / 说唱 / 古典 / 氛围……
- 把情绪视觉化：迷幻 → 高饱和渐变；极简电子 → 几何 + 留白；民谣 → 手作质感 / 暖色调。
- **避免"随便一张图"**：封面必须有概念，能让人一眼联想到音乐风格。

## 3. 构图（方形）

- 方形构图天然适合：中心对称、环形元素、留白 + 小元素、满版纹理。
- 主视觉居中或偏移 1/3，注意四边出血（缩略图会裁切边缘）。
- 黑胶 / 磁带等载体元素可成为封面的一部分（唱盘同心圆、磁带走带窗）。

## 4. 文字排版

- 通常只放 **专辑名 + 艺人名**，字号克制（封面主角是视觉，不是文字）。
- 专辑名在视觉下方或一角；艺人名更小。
- 无文字封面（纯视觉）是常见高级手法，可酌情使用。

## 5. 色彩与质感

- 情绪决定配色：暗黑 → 深底 + 单一亮色；清新 → 低饱和粉彩；复古 → 暖黄 / 米色 + 噪点。
- 质感元素：渐变网格、噪点纹理（SVG feTurbulence）、胶片颗粒、半色调网点。
- 禁止：紫蓝 AI 渐变、纯黑 `#000000`、俗套的"星球 + 星云"。

## 6. 自检清单

- [ ] 封面有明确概念，能传达音乐气质？
- [ ] 方形构图完整，缩略图下依然可辨识？
- [ ] 专辑名 / 艺人名清晰但不喧宾夺主？
- [ ] 质感与配色符合风格？
