# 读书笔记 / 知识卡片设计指南（knowledge-card）

> 读书笔记、知识卡片、金句卡、要点卡。核心是 **信息的结构化呈现**：
> 一卡一主题，要点分层，好读好分享。

## 1. 画布尺寸

| 类型         | 比例 | 尺寸        |
|--------------|------|-------------|
| 横版知识卡片 | 4:3  | 800 × 600   |
| 方版知识卡片 | 1:1  | 1080 × 1080 |
| 竖版读书笔记 | 3:4  | 900 × 1200  |

## 2. 画面结构

- 模板：眉标 → 主问题/主张 → 3~5 条编号要点 → 金句（可选）→ 出处落款。
- 金句卡可极简：大引号（可出血、低透明）→ 引文 → 短横线 → 出处。
- 编号用等宽字并弱化透明度，让正文突出。

## 3. 文案容量

- 标题：主题 / 书名，≤ **16 字**，字号大（≥ 48px）。
- 要点： **3~5 条**，每条 ≤ **18 字**，动词开头；禁止写成完整段落。
- 金句 / 引文 ≤ **40 字**。
- 出处：书名 / 作者 / 页码，小字底部。

## 4. 排版

- 层级：标题 > 要点正文 > 出处注脚；正文 ≥ 28px（小屏可读）。
- 要点用编号 / 圆点 / 图标引导，避免文字墙。
- 系列笔记统一版式与配色。

## 5. 色彩与风格

- 按书目调性取色（文学 → 暖米色，效率 → 清爽蓝绿）。
- 柔和低饱和为主；可用一张配图 / 书影点缀。

## 6. 翻车点

- 一张塞 8 条以上要点。
- 要点写成大段散文。
- 字号过小，缩到 15% 不可读。
- 缺少出处导致可信度不足。

## 7. 自检清单

- [ ] 一卡只有一个主题？
- [ ] 要点 3~5 条、每条 ≤18 字？
- [ ] 金句 / 出处完整？
- [ ] 小屏可读？系列版式统一？
