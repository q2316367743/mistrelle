# 读书笔记 / 知识卡片设计指南（knowledge-card）

> 读书笔记、知识卡片、金句卡、要点卡。核心是**信息的结构化呈现**：
> 一卡一主题，要点分层，好读好分享。

## 1. 画布尺寸

| 类型 | 比例 | 尺寸 |
|---|---|---|
| 横版知识卡片 | 4:3 | 800 × 600 |
| 方版知识卡片 | 1:1 | 1080 × 1080 |
| 竖版读书笔记 | 3:4 | 900 × 1200 |

## 2. 内容结构（一卡一主题）

- **标题**：主题 / 书名 + 章节，字号大（≥ 48px）。
- **要点**：3~5 条核心要点，每条一句话（≤ 30 字），用分点 / 编号清晰呈现。
- **金句**：加引号强调，可单独成块（衬线 / 大字号 / 引用色）。
- **出处**：书名 / 作者 / 页码，小字放底部，体现可信度。

## 3. 排版

- 结构模板：标题 → 要点列表 → 金句 → 出处（自上而下，逻辑清晰）。
- 要点用"编号 / 圆点 / 图标"引导视线，避免文字墙。
- 层级分明：标题 > 要点正文 > 出处注脚；正文 ≥ 28px。
- 金句卡可极简：一句话居中 + 大量留白，高级且好传播。

## 4. 色彩与风格

- 书籍主题色：按书目调性取色（文学 → 暖米色，效率 → 清爽蓝绿）。
- 柔和低饱和为主，阅读舒适；可用一张配图 / 书影点缀。
- 系列感：同系列笔记统一版式与配色（读书笔记常成系列分享）。

## 5. 自检清单

- [ ] 一卡只有一个主题？
- [ ] 要点 3~5 条、每条一句话？
- [ ] 金句 / 出处信息完整？
- [ ] 小屏可读（字号够大）？
- [ ] 系列版式统一？
