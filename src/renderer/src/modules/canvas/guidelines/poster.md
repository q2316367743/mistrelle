# 海报设计指南（poster）

> 电影海报 / 活动海报 / 音乐海报 / 通用宣传海报。海报是"一眼抓住注意力"的艺术，
> 主视觉、大标题、留白与配色决定成败。

## 1. 画布尺寸

| 类型            | 比例       | 尺寸                      |
|-----------------|------------|---------------------------|
| 通用 / 竖版海报 | 3:4        | 1080 × 1440               |
| 电影 / 路演海报 | 2:3        | 1242 × 1863               |
| 横版活动海报    | 16:9       | 1920 × 1080               |
| 音乐 / 巡演海报 | 3:4 或 1:1 | 1080 × 1440 / 1080 × 1080 |
| 故事 / 长竖屏   | 9:16       | 1080 × 1920               |

## 2. 画面结构

- **一个视觉焦点**：主视觉（人物 / 剪影 / 图形 / 大标题即图形）是绝对主角。
- 常用范式：主视觉居中 + 四周留白；左右分屏；三分法 / 对角线。
- **大标题就是海报的灵魂**：字号 80~160px（或短边 10% ~18%），占画面 1/3~1/2 高度，宁可大也不要小气。
- 活动类：主视觉（上 60%）→ 活动名 → 时间地点成组 → 主办方 / 二维码位。

## 3. 文案容量

- 活动名 / 主标题 ≤ **12 字**（电影片名可略长但须一眼可读）。
- 副信息（日期、地点、主办方）成组，每条 ≤ 20 字；不要散落四处。
- 电影风可在底部放密集 credits，但正文区仍保持一个焦点。

## 4. 文字排版

- 主标题：粗字重（700~900）+ 紧字距，可全大写 / 斜体 / 描边字。
- 副信息：16~32px 放标题下方或底部。
- 层级：主标题 → 副标题/类型 → 时间地点 → 落款。
- 文字压图必须可读（半透明遮罩 / 阴影 / 描边）。

## 5. 色彩

- 电影海报常用 **深色基底 + 单一强调色**；强调色只出现一次。
- 活动海报可用明快对比色，仍 ≤1 个强调色。
- 全页一套色板；禁用纯黑 `#000000`、禁紫蓝 AI 渐变（除非锁定风格另有规定）。

## 6. 主视觉来源

- 品牌 logo：`website_logo(url)`，禁止手绘近似 logo。
- 真实图片：image `web` / `stock` / 生图（见 image-generation）。
- 无图时：几何剪影、渐变背景、或让大标题本身成为主视觉。

## 7. 翻车点

- 标题不够大 / 信息平均分布没有主视觉。
- 时间地点散落、不成组。
- 底部贴边（inspect 硬底线失败）。
- 缩到 15% 读不出主标题。

## 8. 自检清单

- [ ] 只有一个视觉焦点？
- [ ] 主标题够大、层级分明、可读？
- [ ] 文案在额度内？时间 / 地点 / 主办方齐全（活动类）？
- [ ] 有足够留白？签名手法落地？
- [ ] 配色克制、与主题情绪匹配？
