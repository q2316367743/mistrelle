# 专辑封面设计指南（album-cover）

> 专辑 / EP / 单曲封面。封面是音乐的一次"视觉转译"：把情绪、风格、概念变成一张图。
> 方形构图的特殊性 + 概念的独特性，是专辑封面的核心。

## 1. 画布尺寸

| 类型               | 比例 | 尺寸           |
|--------------------|------|----------------|
| 标准专辑封面       | 1:1  | 1000 × 1000    |
| 黑胶封面（加出血） | 1:1  | 1400 × 1400    |
| 方形缩略图友好     | 1:1  | 建议 1000~1400 |

## 2. 概念先行

- 先明确音乐气质：电子 / 摇滚 / 民谣 / 说唱 / 古典 / 氛围……
- 把情绪视觉化； **避免"随便一张图"**：封面必须有概念。
- 可从 `canvas_guidelines("styles")` 选气质匹配的签名手法（如蒸汽波、像素、电影海报）。

## 3. 画面结构（方形）

- 适合：中心对称、环形、留白 + 小元素、满版纹理。
- 主视觉居中或偏移 1/3；注意四边出血（缩略会裁切边缘）。
- 黑胶 / 磁带元素可成为构图一部分。

## 4. 文案容量

- 通常只放 **专辑名 + 艺人名**。
- 专辑名 ≤ **16 字**（可分两行）；艺人名更小、不抢主视觉。
- 无文字纯视觉封面是合法高级手法。

## 5. 文字排版

- 专辑名常在视觉下方或一角；字号克制——主角是视觉不是字。
- 避免字喧宾夺主盖住概念。

## 6. 色彩与质感

- 情绪决定配色；质感：噪点、胶片颗粒、半色调、网格渐变。
- 禁止：紫蓝 AI 渐变、纯黑 `#000000`、俗套"星球 + 星云"（除非概念需要）。

## 7. 翻车点

- 没有概念，像库存图拼贴。
- 字太大压死主视觉，或缩略后标题糊掉。
- 四边关键信息被裁切。

## 8. 自检清单

- [ ] 封面有明确概念，能传达音乐气质？
- [ ] 方形构图完整，缩到 15% 仍可辨识？
- [ ] 专辑名 / 艺人名清晰但不喧宾夺主？
- [ ] 质感与配色符合风格？签名手法落地？
