# 社交媒体配图设计指南（social-media）

> 公众号封面 / 小红书配图 / 头图 Banner / OG。核心是 **小屏可读 + 手机端传播**：
> 缩略图时代，文字要大、视觉要强、信息要一眼懂。

## 1. 画布尺寸与安全区

| 类型              | 比例       | 尺寸                        | 安全区 / 注意                                                                             |
|-------------------|------------|-----------------------------|-------------------------------------------------------------------------------------------|
| 公众号头条封面    | 2.35:1     | 900 × 383                   | **列表页常裁成 1:1 取中间**——主标题落在水平中段；编辑器侧栏也可能挡左缘，关键字勿贴左右边 |
| 公众号次条 / 方图 | 1:1        | 900 × 900 / 500×500         | 缩略偏小；主体收进中心约 **80%**，四角勿放关键字                                          |
| 小红书竖版封面    | 3:4        | 1080 × 1440（或 1242×1660） | **底部约 18% 被平台标题与头像盖住**，落款与 CTA 往上收                                    |
| OG / 链接预览     | 1.91:1     | 1200 × 630                  | 各平台裁切不一，**四边留约 8%**；标题字号 ≥ 64px                                          |
| 横版 Banner       | 16:9 / 5:2 | 1920×1080 / 1500×600        | 左右勿贴关键信息（信息流可能裁成 16:9）                                                   |

## 2. 画面结构

### 公众号头条

- 结构建议：左侧色带或品牌标 → 眉标（栏目/期号）→ 主标题 2 行 → 底部落款 + 日期。
- 关键词可染强调色（只出现一次）。

### 小红书封面

- 顶部胶囊标签（可微旋转）→ 超大标题 2~3 行（约占高 35%+）→ 中部留白 → 底部编号清单 3~5 条（避开底 18%）→ 落款 @账号。
- 高饱和底色 + 高对比字更抓眼。

### OG

- 品牌标（小）→ 标题（大，压左，最多 3 行）→ 一句副标 → 域名/作者。

## 3. 文案容量

- 公众号主标题 ≤ **16 字**，拆成 2 行；眉标 ≤ 12 字符。
- 小红书封面标题每行 **4~6 字**，总字数宜 ≤ **12~16 字**；清单每条 ≤ 14 字，≤ 5 条。
- OG 标题 ≤ 24 字，副标 ≤ 30 字。
- 一个封面只表达 **一个**核心钩子。

## 4. 构图与排版

- 手机端：正文 ≥ 24px，标题 ≥ 64px（或短边 10%+）。
- 留白与对齐：缩略图下，干净比复杂更吸引点击。
- 系列感：同账号统一版式 / 色调。

## 5. 翻车点

- 小红书：标题不够大；关键信息落在底部 18% 遮挡区；清单超过 5 条；浅灰字。
- 公众号：标题 3 行以上；重要信息贴左右边缘或落在裁切区外中轴。
- OG：把整篇摘要塞进图；低对比字。
- 缩到 15%（或更小）读不出主标题。

## 6. 自检清单

- [ ] 关键文字在安全区（小红书避底 18%；公众号顾中轴与边距；OG 四边 8%）？
- [ ] 标题大而少，缩略可读？
- [ ] 文案在额度内？一个封面一个核心信息？
- [ ] 配色明快、系列感统一？
