# 书籍封面设计指南（book-cover）

> 实体书 / 电子书封面。封面是"书架上的三秒竞争"：远看有辨识度，近看有细节。
> 书名是绝对主角，字体气质决定书籍调性。

## 1. 画布尺寸

| 类型                | 比例     | 尺寸                               |
|---------------------|----------|------------------------------------|
| 竖版封面（正面）    | 2:3      | 900 × 1350                         |
| 标准开本            | 3:4      | 900 × 1200                         |
| 横版（画册 / 图录） | 4:3      | 1200 × 900                         |
| 含书脊三联          | 约 11:16 | 例如 前端 900 + 书脊 80 + 封底 900 |

## 2. 画面结构

- **书名是绝对主角**：字号大（≥ 96px 或短边 10%+），位置醒目。
- 元素克制：书名 + 作者名 + 出版社 + 一个主视觉。
- 常见范式：居中书名 + 留白；满版图案 + 小书名；几何构成。

## 3. 文案容量

- 书名 ≤ **12 字**（可分两行，语义处断）。
- 副标题 / 系列名 ≤ **20 字**。
- 作者名、出版社名短且规范，勿与书名抢视觉。

## 4. 文字排版

- 字体随气质：文学 → 衬线；科技工具 → 无衬线紧字距；悬疑 → 大字号克制配色。
- 层级：书名 → 副标题 → 作者 → 出版社（常置底）。
- 中文书名可竖排增强书籍感。

## 5. 色彩

- 配色与内容调性一致；经典手法：单色背景 + 高对比书名。
- 禁止：纯黑 `#000000`、花哨多色、紫蓝 AI 渐变。

## 6. 主视觉来源

- 图案化（几何 / 渐变 / 线条）往往比写实图更耐看。
- 写实封面给图片留够面积；真实 logo 用 website_logo。

## 7. 翻车点

- 书名不够大，远看（缩到 15%）认不出。
- 元素堆砌、作者名喧宾夺主。
- 字体气质与题材不符。

## 8. 自检清单

- [ ] 书名是视觉第一眼？
- [ ] 字体气质与题材匹配？文案在额度内？
- [ ] 作者名与出版社名位置规范？
- [ ] 远看能辨识标题与色调？配色克制？
