# 小红书爆款标题生成

核心原则：标题同时干两件事——①在信息流里被划过时拽停手指（情绪 + 人群 + 缺口）；②在搜索框里被搜到（关键词命中）。只做到①的活三天，两件都做到的吃半年长尾流量。

## 平台事实校准（别用公众号的直觉写小红书）

- 【平台规则】**硬上限 20 字符**（emoji 占字符位），最佳区间 **13~18 字**，超长被截断、句尾信息丢失
- 【平台规则】**小红书是搜索型社区**，笔记持续吃搜索与「搜索后推荐」流量，标题里没有用户会打进搜索框的词 = 放弃长尾。此点权重远高于公众号
- 【经验】一个押准的搜索词胜过三个堆上去的词（「油皮粉底液」优于「美妆 好物 粉底 推荐」）；关键词堆叠会被判营销
- 【经验】强第一人称、强口语（「我」「姐妹们」「谁懂啊」）——书面腔是劝退信号
- 【经验】emoji 是标配：1~2 个，句首吸睛或句尾定情绪，**超 3 个被判营销号**
- 【经验】人群标签前置：「学生党」「i人」「小个子」「新手妈妈」「油皮」——读者半秒确认「说的是我」
- 【经验】高收藏结构吃香：数字清单 +「建议收藏」「码住」「照抄就行」；收藏是最强正反馈信号之一
- 【经验】负向选题（踩雷/别买/劝退/后悔没早知道）点击率长期高于种草类
- 【经验】符号习惯：`｜` 竖线分区最常见，其次感叹号、问号、括号补语；冒号不如公众号常用

不应误读：加了「救命」和 emoji 不会自动爆。标题只优化「点进来」和「搜得到」两段，数据还由封面、账号标签、发布时段、正文留人共同决定。

## 15 种方法（至少覆盖 6 种；每条一个主方法，最多叠 1 个辅助）

| # | 方法 | 公式 | 红线 |
|---|---|---|---|
| 1 | 人群标签前置 | `[人群词]｜[具体处境]+[结果]` | 人群词必须是正文真服务的对象，硬贴拉低账号标签精度 |
| 2 | 搜索词卡位 | `[核心搜索词]+[限定条件]+[差异化后缀]` | 不硬塞无关热词，堆词限流 |
| 3 | 数字清单 + 收藏指令 | `[数字]+[品类/方法]+[建议收藏/码住/直接抄]` | 数字必须与正文条目数一致，骗收藏掉差评 |
| 4 | 避雷劝退（负向） | `[品类]+别买/千万别+[代价]` 或 `我踩过的[N]个坑` | 点名负面必须是真实体验且限定主观感受；没真用过写品类通用坑，不点名 |
| 5 | 后悔体 | `后悔/居然/竟然+没早知道+[具体的事]` | 必须真有信息增量，常识配「后悔」= 标题党 |
| 6 | 情绪惊叹（救命体） | `救命/天呐/谁懂啊+[对象]+[强反应]` | 单用很空，必须配具体对象并与方法 2 叠加保搜索价值 |
| 7 | 亲测对比 | `[时长/动作]后+[可观测变化]` 或 `[A] vs [B]` | 没真实做过不得写「亲测」「实测」；写自己的感受，不写疗效 |
| 8 | 保姆级教程 | `零基础/新手/小白+[目标]+保姆级/N步搞定` | 正文必须真 step-by-step 且步数与标题一致 |
| 9 | 反常识纠错 | `原来/其实+[常见做法]+是错的` 或 `别再[X]了` | 反的必须真是错误做法，不为反转而反转 |
| 10 | 悬念缺口 | `[人群]+[强评价]+不说明对象` | 慎用：藏掉关键词同时损失搜索流量，必须至少保留 1 个可搜索词 |
| 11 | 场景具体化 | `[具体时间/地点/困境]+[依然做到了什么]` | 场景是真实生活，不编造人设经历 |
| 12 | 平替/省钱 | `[预算数字]+搞定/买齐+[目标]` 或 `[贵价对象]的平替` | 价格须真实并注明时间/渠道口径；不能宣称与大牌「效果相同」（虚假宣传） |
| 13 | 时间承诺 | `[时长]+[投入]+[结果]` | 时长与结果须来自真实经历，不承诺他人复现 |
| 14 | 求助/提问 | `[具体选择困境]+在线等/求推荐/怎么选` | 正文要接得住讨论；互动高但搜索价值低，不作账号主力 |
| 15 | 节点/季节/热点绑定 | `[节点词]+[人群/预算]+[具体产出]`；变体「第一批[X]的人已经[Y]」 | 热点须真实相关，社会事件/灾难一律不蹭；「第一批」不得杜撰 |

**慎用型**（张力强但易违规或透支信任）：绝对化拔高（「最好用」——审核严于公众号，极易限流）、焦虑恐吓（「不看后悔一辈子」）、收入数据炫耀（「月入 5 万」——重点审核对象，只能写成个人经历）。

## 10 个增强器（加辣不叠加事实：改的是表达，不往标题里加正文没有的东西）

人群词前置 ｜ `｜`竖线分区 ｜ emoji 定调（≤3 个）｜ 口语化换词（「提升效率」→「不用加班了」）｜ 搜索词补位（没有真会搜的名词就换掉一个形容词）｜ 收藏钩子加尾（仅内容真可复用时）｜ 模糊词换具体数字（「很多」→「7个」）｜ 第一人称化 ｜ 用户原话加引号（`"这也太难删了吧！"`——须是真实听过/正文出现过的说法，不编造证言）｜ 身份反差（`理发师朋友劝我别买`——反差身份须真实存在于正文）

## 工作流程

1. **判断输入**：给主题起标题 → 走第 2 步；优化现有标题 → 先做文末「改写现有标题」的诊断，再回第 4 步
2. **建内容简报**：目标人群自称词、3~5 个候选搜索词、核心对象、可兑现结果、证据资产（真实数字/价格/时长/前后对比/用户原话——比任何形容词都值钱，一定先抓出来）、情绪基调、收藏理由、时效等级（常青内容把搜索词权重拉满；节点内容才押节点词）、事实边界（正文没证明的结论/效果/价格/排名不许进标题）、合规风险点。信息不足先出保守版并说明缺什么限制了强度——**不靠编造补强度**
3. **按内容类型路由**：

| 内容类型 | 优先方法 | 不宜优先 |
|---|---|---|
| 好物种草/测评 | 亲测对比、平替省钱、人群标签、避雷 | 纯悬念、求助 |
| 干货教程/工具 | 数字清单+收藏、保姆级、搜索词卡位 | 情绪惊叹单用 |
| 避雷拔草/辟谣 | 避雷劝退、反常识、后悔体 | 绝对化拔高 |
| 探店/旅行/路线 | 搜索词卡位（地名必进）、节点季节、场景 | 悬念缺口 |
| 穿搭/美妆 | 人群标签（身材/肤质）、亲测对比、求助 | 数据炫耀 |
| 个人成长/Vlog | 时间承诺、场景、后悔体、第一人称反差 | 数字清单 |
| 情绪共鸣/吐槽 | 情绪惊叹、场景、求助 | 保姆级 |
| 知识科普/答疑 | 反常识、搜索词卡位、数字清单+收藏 | 情绪单用、悬念 |
| 家居/母婴/装修 | 避雷、亲测对比、平替、场景 | 绝对化拔高 |
| 商单/品牌合作 | 人群标签、场景、搜索词卡位（品牌/品类词必进） | 避雷、绝对化、功效断言、数据炫耀 |
| 素材弱、没硬料 | 搜索词卡位、场景、求助 | 亲测、数字、平替 |

4. **批量生成**：默认 **12 个候选、至少 6 种方法**（用户要可扩到 20），覆盖搜索型/清单型/避雷型/体验型/情绪型/场景型各 1~3 个。只在正文支持时用对应方法：没真用过不写「亲测」，没有 N 条不写数字，没有价格凭据不写具体金额。逐条自检字符数，超 20 字砍到 18 字内再评分
5. **评分 → 删同质 → 合规校验** → 按输出协议交付

## 评分规则（百分制，逐维打分，不凭感觉报总分）

| 维度 | 分值 | 判断 |
|---|---:|---|
| 内容兑现度 | 20 | 正文能否兑现标题承诺 |
| 搜索词覆盖 | 15 | 有无至少 1 个用户真会搜的名词、是否主流搜法 |
| 人群指向性 | 15 | 目标人群能否半秒确认「说的是我」 |
| 情绪与钩子 | 12 | 有让人停手指的情绪点或缺口 |
| 收藏动机 | 10 | 有清单/教程/避雷等可复用理由 |
| 具体性 | 10 | 有明确对象/数字/场景，非空泛形容 |
| 字数与节奏 | 8 | ≤20 字符、重点前置、一遍读懂 |
| 口语与平台感 | 5 | 像小红书用户说的话，不是公众号腔 |
| 独特性 | 5 | 区别于同主题满屏写法 |

**直接淘汰**：超 20 字符｜核心承诺正文无法兑现｜捏造数字/价格/亲测/条目数/排名｜触碰违规红线任一条。
**强制扣分**：把推测/个例写成普遍事实 −15｜无可搜索名词 −15｜夸大因果或「人人都该买」 −12｜硬贴人群词 −12｜主观感受写成客观效果 −12｜无依据的「最/第一/永久」 −12｜纯情绪无对象 −10｜数字与正文条目不符 −10｜悬念藏光关键词 −8｜emoji 超 3 个 −5｜书面腔 −5。

**风险分级**：低（事实都在正文、无功效/绝对化、人群词准）｜中（强情绪、点名品牌、价格时长承诺——标出待核验的词）｜高（功效/医疗/收益、绝对化、未经证实负面指控）——**高风险不得做综合首选**，且必须写清「为什么高风险 + 安全改法」。

## 平台违规红线（限流级，逐条过）

1. **医疗与功效**：禁「治疗/祛痘/祛斑/美白/瘦身/抗炎/生发」等断言 → 写主观感受与可观测现象（「上脸没有闷痘」）
2. **绝对化用语**：禁「最好/第一/顶级/销量冠军/百分百/永久」 → 限定个人视角或换成具体差异点
3. **收益与投资承诺**：禁「稳赚/包过/月入 X 万」 → 写个人经历且不承诺可复制
4. **虚假与夸大**：不捏造前后对比、不编亲测、不虚标价格、不伪造条目数
5. **点名贬损**：不对具体品牌做未经证实的负面指控，主观体验须标明个人感受
6. **诱导与导流**：不出现「加V」「私信领取」「进群」「关注领资料」
7. **敏感与擦边**：软色情、性别对立、地域攻击、灾难蹭热点一律不做
8. **未成年人**：不做涉及未成年人的容貌、身材评价类标题

判断口诀：这句话截图发到平台举报入口能不能站得住？站不住就改。

## 输出协议

1. **内容简报**（4~6 行）：人群及自称词、候选搜索词、核心对象、最大爆点、可用证据、事实与合规边界
2. **候选矩阵**：候选标题｜字符数｜方法｜钩子/搜索词｜评分｜风险（方法标「主方法 + 辅方法」，钩子栏必须标押的是哪个搜索词，中高风险写原因）
3. **Top 5 按用途分角色**（不按分数机械排）：**综合首选**（三项最平衡）/ **搜索版**（吃长尾，适合常青笔记）/ **爆点版**（冲首发流量）/ **收藏版** / **稳健版**（零合规风险，适合商单、专业号）；每条一句话说明理由并点出得分项与扣分项；5 个来自同一方法时，用略低分但方法不同的候选替换
4. **A/B 建议**（2~3 组，每组只改一个变量，且必须写清看哪个指标）：有/无 emoji、人群词前置 vs 结果前置、清单 vs 单点故事、正向 vs 负向、陈述 vs 提问。情绪/emoji/反差类 → 看**点击率**；搜索词/人群词类 → 看**搜索进入占比与 7 天长尾**（首日不作数）；清单/收藏钩子类 → 看**收藏率**。两条笔记的发布时段、封面要尽量一致
5. 用户选定后用 `article_write` 落盘（一篇笔记一个单元，type 用「小红书」）

**一致性硬要求**：核心搜索词必须在**标题、正文首句、话题标签**三处同时出现，只在标题出现会被稀释。

## 改写现有标题

1. **诊断**（逐项打勾/打叉）：字符数是否超限 / 有无可搜索名词 / 有人群指向 / 有情绪或缺口 / 有收藏理由 / 是否公众号腔 / 是否触碰违规词
2. **保留资产**：原标题已有效的搜索词、真实数字、准确人群词，改写时**不要改掉**
3. **产出至少 12 个改写版**（覆盖 ≥4 种方法）：3 个**稳健优化**（只修字数、口语、搜索词）+ 6 个**换方法重写** + 3 个**激进测试**（情绪/反差拉满，风险自标），逐条标注类别与改动变量
4. 别把「更夸张」当唯一优化手段——很多标题的问题不是不够刺激，而是没有一个词能被搜到

## 红线（总纲）

- 不捏造数字、价格、条目数、亲测经历、排名、独家。**可以留缺口，不能撒谎**
- 不写功效断言、绝对化用语、收益承诺——在小红书是限流级问题，不只是可信度问题
- 不硬贴人群标签、不堆无关关键词——污染账号标签，长期比单条限流更伤
- 缺口再大，点进去必须兑现：标题党到货不对板会掉粉、掉收藏、拉低完播
- 「爆款」不是承诺结果，只优化「被点开」和「被搜到」这两段可控的部分

## 接力

写正文 → `xhs-writer`（交接：定稿标题 + 押中的 3~5 个搜索词，正文首句与标签要呼应）｜封面 → `xhs-cover`（封面文案再压缩到 ≤12 字 + 情绪基调）｜没选题 → `xhs-hotspot`（有定位缺选题）或 `xhs-positioning`（没定位）｜发出去没人点 → `xhs-note-analytics`——**CTR 低才是标题/封面的锅；曝光本身就低说明问题在上游，别乱改标题**。
