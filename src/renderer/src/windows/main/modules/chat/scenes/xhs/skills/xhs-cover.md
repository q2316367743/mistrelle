# 小红书封面

把内容整理成一张第一眼能看懂、愿意点开的封面。封面只干一件事：让人在信息流里停下来。

本 skill 只管封面与封面变体：正文组图走 `xhs-cards`；位图风格的信息图 / 组图走 `xhs-image`。

## 两条落地路线（先选一条）

1. **画布排版（默认推荐）**：`canvas_create({ width: 1080, height: 1440, title: '封面' })` 建封面页 → 标题与副标题用 **text 节点**排（逐字准确、可随时改）→ 主体 / 背景素材用 `image_generate` 或用户实拍图，填进 image 节点。导出即标准 1080×1440。
2. **生图直出**：`image_generate` 一次生成含字的整张封面。快，但**中文错字风险高**，出图后必须逐字检查；同一文字连续两次仍不准确 → 走「无字底图回退」（生成无字底图 + 预留标题区，回到路线 1 用 text 节点叠字）。

## 默认设置（用户未指定就直接采用，不要为常规选项反复追问）

- 画幅 3:4（1080×1440）；数量 1 张；风格由主题智能匹配
- 文案：1 个主标题（6-14 个汉字，1-3 行）+ 可选 1 个副标题（≤22 字）
- 视觉顺序：主标题 → 主体 → 副标题；主标题必须是第一视觉
- 画面至少保留约 20% 呼吸空间；重要内容距四边至少约 10%
- **底部约 18% 会被平台标题与头像盖住**：落款与关键信息往上收
- 账号名只在用户明确要求时添加，放弱层级

用户说「直接做」「你来定」「按内容匹配」时，直接做合理选择并推进，不暂停等待。

## 输入清单（优先从用户已有内容里提取）

主题或正文 / 主标题（没有就由内容提炼）/ 副标题（可省）/ 主体（人物、产品、食物、空间或抽象主题）/ 主体图片（可选）/ 背景图片（可选，可多张）/ 风格或风格参考（可选）/ 字体倾向、配色、装饰、自由说明（可选）/ 变体数量（默认 1，可 3 或 6）/ 账号名（仅用户要求时）。只有缺少会改变任务本质的信息时才问。

## 工作流

### 1. 理解内容

先判笔记类型（教程清单 / 经验复盘 / 观点判断 / 对比测评 / 工具推荐 / 职场专业知识 / 产品介绍 / 生活方式 / 探店旅行 / 个人品牌），再提取三点：用户最想让读者记住什么、哪个词最能制造识别或兴趣、什么最适合当画面主体。

### 2. 整理标题

用户给了明确标题就保持原意（除非授权优化）；只给正文时给 3 个短标题候选并推荐 1 个。标题要具体可感，优先数字、对象、结果、场景、反差；不堆夸张词、不用空洞口号。

拆行规则：一行只承载一个语义块；关键词独占一行或上强调色；避免单字孤行；中英混排保留完整英文词组；标点尽量少；封面不写长段正文。**封面文案总字数宜 ≤16 字**。

### 3. 匹配风格

从下方风格库按内容推荐 4 种方向 + 一句话差异（用户已指定或要求直接做就跳过）。同一批变体保持标题与主体一致，只改构图 / 配色 / 字体气质 / 装饰系统 / 背景处理——**只换一个颜色不算新变体**。

### 4. 标记图片角色

- **主体图**：人物或产品的身份必须保留
- **背景图**：只取环境、纹理、氛围、地点
- **风格参考**：只提取视觉语言，不复制标识、文字或独特素材

主体保真：保留人物身份、脸部特征、发型、服装与姿势（除非用户要求改变）；保留产品外形、包装、标识位置与关键结构；标题不能压住脸、手、产品名或关键卖点；背景服务主体，不制造第二个视觉中心。

生图路线把主体图路径填进 `image_generate` 的 `referenceImagePaths`（按参考图重绘）；没有输入图就省略该参数。

### 5. 设计构图

| 构图 | 适合 |
|---|---|
| 左字右人 | 人物观点、职场、个人品牌 |
| 上字下物 | 产品、美食、空间 |
| 中央主体 | 强人物或单一产品 |
| 分屏对比 | 前后变化、方案对照 |
| 背景大字 | 观点、趋势主题 |
| 清单卡片 | 步骤、工具、知识总结 |
| 横幅标签 | 探店、旅行、活动 |
| 拼贴组合 | 复盘、合集、多场景 |

一张封面只保留一个主构图，装饰簇最多 3 组；不要把正文页的信息量塞进封面。

### 6. 制作

**生图路线**提示词骨架（`image_generate` 的 prompt，逐项填满）：

```
制作一张 3:4 竖版小红书封面（最终 1080×1440）。
主题 / 目标读者 / 希望传达的核心价值：[…]
封面文字必须逐字准确：主标题第一行「…」/ 第二行「…」/ 副标题「…或无」
除以上文字外，不要生成任何其他文字、字母、数字、水印、签名或标识。
输入图角色：图 1 是[主体图/背景图/风格参考]，[使用方式]
构图 / 风格 / 字形气质 / 配色（底、字、强调色）/ 强调词 / 装饰（≤3 组）：[…]
主标题是第一视觉，主体第二，副标题第三；四边留 ≥10% 安全边距，画面留 ≥20% 留白；
手机缩略图下仍一眼可读；标题不遮挡人物脸部、双手、产品名；中文笔画完整、无乱码、无错字。
```

- 人物主体：严格保留身份与五官，可做自然光与背景融合，不磨皮、不新增首饰或文字
- 产品主体：严格保留外形、颜色、包装比例、按钮接口与已有标识位置，不新增虚构包装文字
- 多张背景图：逐张说明各提供什么（空间光线 / 桌面材质 / 远处轮廓），融合成一个可信背景，不做图片拼盘
- 风格参考：只取留白比例、色彩关系、标题层级、材质，不复制其中人物、标识、文字与完整布局
- 带文字出图时一次只生成一张变体：3 张用「强标题 / 强主体 / 强氛围」；6 张在「左字右人浅色、背景大字黑白、中央主体海报感、清单卡片、分屏、拼贴」上形成真差异

**画布路线**：先铺背景与主体（image 节点），再按「主标题 → 副标题 → 装饰」用 `canvas_batch_edit` 加 text 节点（每批 ≤15 个操作）；字号参考 主标题 88-128px、副标题 36-44px；用 `canvas_inspect` 核对有没有压到底部 18%。

### 7. 检查与修正

每张出来必须看：主标题是否逐字正确；有没有乱码、重复字、错别字或多余文字；**缩到手机缩略图大小还能不能在 2 秒内读懂**；主标题是不是第一视觉；人脸、双手、产品与关键标识是否完整；留白够不够；字体颜色装饰是否统一；四周安全边距是否留够。**不要文字错误的图当成品交付。**

局部问题就定向改，不要整张重来（生图路线示例）：

```
只修正封面文字：把「[错误文字]」准确替换为「[正确文字]」，字数、换行、位置保持一致；
人物、背景、构图、颜色、光线与其他元素全部不变；不要新增任何文字。
```

### 8. 落盘与交付

- 封面页 `title` 用「封面」，方便右侧画板下拉里一眼认出
- 导出：`canvas_export`（画布页导出即 1080×1440）或按用户要求指定 `path` 存到文章 assets 目录；命名 `cover-01.png`，已存在同名就用 `-v2`，**不静默覆盖**
- 生图路线的位图先用 `image_info` 核对尺寸与比例，再作为 image 节点放进封面页（保证最终导出是标准 3:4）
- 交付时给：成品路径、实际尺寸、采用的风格、变体之间的一句话差异、存在的限制

## 封面风格库（按内容匹配，再做审美）

| 风格 | 适用 | 构图与配色要点 |
|---|---|---|
| 01 清单大字 | 工具合集、步骤教程、知识总结 | 主标题占上半区 + 底部 3-5 个短标签；白底 + 单一高饱和强调色 |
| 02 专业留白 | 财务、职场、商业、AI、方法论 | 左字右人或上字下卡片，留白明显；白 / 浅灰 + 深色字 + 橙蓝绿点缀 |
| 03 手绘便签 | 经验分享、学习笔记、入门教程 | 便签、胶带、箭头、少量涂鸦；奶油白 + 浅黄粉绿 |
| 04 霓虹撞色 | AI、科技、效率工具、新趋势 | 深底大字或亮底深字，主体带轮廓光；紫蓝 + 荧光绿 / 玫红（≤3 色） |
| 05 编辑感宋体 | 观点、女性成长、审美、书影音 | 大留白 + 一张质感主体图；米白 / 黑 / 酒红 / 墨绿，粗宋配细黑 |
| 06 分屏对比 | 改造前后、方案比较、错误与正确 | 左右或上下分屏 + 清晰关系标记；两侧冷暖或明暗差异 |
| 07 背景大字 | 观点判断、趋势观察、个人态度 | 超大关键词作背景，主体覆盖其前；黑白 + 1 强调色 |
| 08 温暖生活 | 家居、美食、日常、旅行、亲子 | 场景图占主体，文字放自然留白区；奶油 / 木色 / 浅绿 / 暖橙 |
| 09 个人品牌 | 知识博主、职业经验、系列栏目 | 人物稳定占 35%-50% + 固定栏目标签；长期固定 1 品牌色 + 1 辅助色 |
| 10 探店横幅 | 餐厅、咖啡店、展览、旅行地点 | 场景或食物照为主 + 横幅承载标题；从照片提主色，横幅强对比 |
| 11 深色科技 | AI 工具、代码、自动化、数码 | 深底 + 网格线框 + 少量界面卡片；深蓝黑配青紫绿 |
| 12 复古拼贴 | 复盘、故事、城市、穿搭、灵感 | 1 主图 + 2-3 个局部切片，纸张印刷质感；米色 / 红 / 蓝 / 棕 |

同一画面最多 2 个主色 + 1 个强调色 + 3 组装饰。字体气质：粗黑体（强标题 / 科技 / 清单）、现代黑体（商业 / 职场）、粗宋（观点 / 审美）、圆体（生活 / 入门）、手写体（日记 / 经验）、等宽英文（代码 / 数码）——**描述字形气质，不写臆造字体名**；画布路线需要真实字体时用 `font_list` 查本机字体。

## 内容与视觉边界

- 不自动添加账号名、水印、二维码或平台标识；不复制参考图中的品牌签名、人物身份、专属角色或受保护元素
- 不捏造功效、收益、排名或专业背书；金融 / 医疗主题的免责声明不进封面（提醒用户放正文）
- 不使用他人 Logo、商标或未授权素材冒充官方视觉
