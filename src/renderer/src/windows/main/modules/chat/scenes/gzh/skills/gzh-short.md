# 公众号短文写作

**1000 字以内，纯文字，不配图。** 写一个观察、一次实测、一段判断，或把长文 / 素材压成短文。

短文不是长文的缩水版：长文靠结构和论证取胜，短文靠**一个足够锐利的点 + 干净的节奏**取胜。1000 字里塞三个观点，等于一个都没说清。

## 平台事实（先记住，避免白写）

| 形式 | 上限 | 说明 |
|---|---|---|
| **图文消息**（默认） | 正文无上限 | 有标题有封面。1000 字是编辑目标，不是平台限制 |
| 群发纯文字 | **300 字** | 没有标题和封面，超出发不出去 |
| 自动回复纯文字 | 600 字 | |

默认按图文消息写（有标题）。作者明确要发「纯文字群发」时砍到 300 字以内并去掉标题。

## 核心风格规则

### 1. 第一人称，不说教（最重要）

整篇像分享自己的观察，不是指导读者：「你日常用的软件」→「日常用的软件」；「大家可以试试」→「我试了一下」。**全篇「你」字不超过 1 次，最好为 0**；例外是结尾的行动引导（「你要是也在用，评论区聊聊」）。

### 2. 有观点，不端着

敢下判断：「说难听点就是收智商税」「确实好用，但贵得离谱」。不两头讨好（别每句都「一方面……另一方面……」）；不用学术腔（笔者认为 / 综上所述）；不用鸡汤腔（共勉 / 一起加油）。

### 3. AI 腔黑名单（出现即删）

共同特征：**读起来像给读者做翻译，而不是表达自己的想法**。

- 本质上就是 / 说白了就是 / 换个角度看 / 换句话说 / 背后的逻辑是一样的
- 「不是 X，而是 Y」全篇最多 1 次；三段排比收尾（是……是……更是……）直接砍

**例外——自问自答是好东西**：问句独立成段、后面紧跟**具体**回答，是节奏工具。它变 AI 腔是因为后面跟空泛概括：✅「这意味着什么？」→「以前是我盯着它写，现在是它自己拆任务、自己跑」；❌「这意味着什么？」→「AI 正在深刻改变我们的工作方式」。**判定法：把问句和答句一起删掉，文章没损失任何信息，就是 AI 腔。**

### 4. 标点与格式

- 引号统一 `""`，不用「」；破折号 `——` 全篇 ≤2 次
- 不用 emoji，不用 hashtag（公众号话题标签除外）；英文产品名保持原样
- 编号观点的标题**不加粗**：写 `1 命令行`，不写 `**1 命令行**`，像随手记笔记
- 纯文字没配图撑场，全靠分段做呼吸：手机一行约 22–24 字，**单段超 70 字就断**

### 5. 结构骨架（一篇只用一种，拿不准选 B）

**骨架 A：编号观点式**（几个并列观察）

```
一句引入（一个疑问 / 具体场景）
1 观点 + 2-3 句展开
2 观点 + 2-3 句展开
（≤4 个，超过就该写长文）
串联段：这几个点加在一起说明了什么
收尾：一个具体画面
```

**串联段是骨架 A 的命门**——没有它文章就是个 list 不是 insight，读者「看了几条信息」而不是「想明白一件事」。

**骨架 B：单点推进式**（一个认知转变）：切身事件开头 → 三到四段递进分析（每段 3-5 句）→ 回到个人立场一个干脆的判断。**1000 字讲透一个点，比列四个点更有记忆点。**

### 6. 开头：不要预热

公众号读者是订阅者，但没人有耐心看铺垫。❌「最近大家可能都注意到一个现象……」；✅「昨晚更新完，我第一件事是去翻了它的连接器列表」；✅「花了 68 块钱，跑了三个小时，结论有点意外」。**第一句就该有具体信息**——摘要不填会自动截取正文开头，这句话会出现在消息列表里。

### 7. 收尾：具体画面 > 抽象判断

❌「AI 正在深刻改变内容行业」；✅「身边写公众号的朋友，现在打开电脑第一件事不是新建文档，是把素材扔给 Agent，然后去倒杯水」。收尾后接**一个**行动引导（留言 / 在看 / 读上一篇），只给一个。

## 写作流程

1. **定唯一的点**——这篇要让读者记住的一句话，写不出先别动笔
2. 选骨架（A / B，拿不准选 B）
3. 开头：具体场景或数字，不预热
4. 展开：每段 3-5 句，砍掉不增加信息量的字
5. 串联段（骨架 A 必须有）
6. 收尾：具体画面 + 一个行动引导
7. 过检查清单

## 输出前检查清单（逐项过，不许跳，输出时附检查结果）

```
□ 字数 ≤1000（纯文字群发则 ≤300）
□ 「你」字：除结尾引导外为 0
□ AI 腔黑名单：本质上 / 说白了 / 换句话说 / 不是…而是
□ 自问自答处：答句具体吗？删掉损失信息吗？
□ 「」已全部换成 ""；破折号 ≤2 次
□ 编号标题没被加粗
□ 最长段落 ≤70 字
□ 骨架 A 有串联段；收尾是具体画面；行动引导只有 1 个；全篇只讲一个点
```

## 特别注意

- **压缩不是节选，是重新提炼**——挑最锐利的一个点重写，不是把长文每节保留一句
- 素材观点超 4 个时主动建议：砍到 1 个写短文，或转 `gzh-write` 写长文
- 保持作者本人的立场和锋芒，**不中和掉原文的判断**；不编造数据、案例、经历
- 用户说「用我的风格」时，以个性化设定（WRITE.md）为最高优先级文风约束
- 成稿用 article_write 写入当前文章项目，写完告知字数
