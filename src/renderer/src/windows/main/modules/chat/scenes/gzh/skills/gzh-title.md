# 公众号爆款标题生成

方法论提炼自 1000 篇真实 10w+ 样本。核心校准事实： **标题字数中位 22 字；66% 含具体实体（人名 / 产品 / 地名 / 事件）；仅 30%
含数字**——先锚定强实体，别硬塞数字。

## 第 0 步：建内容简报（生成前必须完成）

从文章或用户描述中提炼，缺项就问：
核心对象（谁 / 什么）· 关键变化（发生了什么）· 读者价值（读完能得到什么）· 证据（数据 / 案例）· 张力（冲突 / 反差）· 情绪（愤怒 /
焦虑 / 惊喜 / 暖）· 时效（是否蹭热点）· **事实边界**（哪些不能夸大）

## 第 1 步：按内容类型选方法

| 内容类型      | 优先方法                         |
|---------------|----------------------------------|
| 新品 / 新发现 | 强时效、隐藏机制、极值           |
| 人物 / 故事   | 亲测转变、对话剧本、反差转折     |
| 观点 / 评论   | 冲突对立、阴谋揭秘、身份场景     |
| 攻略 / 教程   | 任务结果、生活痛点、具体场景画面 |
| 数据 / 盘点   | 数字反差、极值、收益损失         |
| 节点 / 热点   | 强时效、问题悬念                 |

## 第 2 步：16 种方法（至少覆盖 6 种，默认产 10–12 个候选）

强时效 · 实体锚定 · 数字反差 · 极值 · 阴谋揭秘 · 冲突对立 · 反差转折 · 亲测转变 · 任务结果 · 生活痛点 · 身份场景 ·
收益损失 · 对话剧本 · 问题悬念 · 隐藏机制 · 具体场景画面

通用增强器（加辣不叠加事实，每个标题最多叠 1 个）：加紧迫感、加人群限定、加结果前置、加悬念留白、加身份代称、加具体数字、加反常识词。

## 第 3 步：评分与分级

每个候选百分制 8 维：具体性 · 张力 · 价值感 · 时效 · 情绪 · 搜索友好 · 与内容相符 · 平台合规。 **强制扣分**：标题党与内容不符
−30、绝对化用语（最 / 第一 / 必看）直接淘汰。

风险分级：低风险（放心用）/ 中风险（吸引点击但有落差）/ **高风险（不得做首选）**。

## 第 4 步：输出协议

1. 内容简报（让用户确认理解没偏）
2. 候选矩阵表：标题 | 方法 | 评分 | 风险
3. Top 5 按用途分角色： **综合首选** / 稳健备选 / 传播款 / 搜索款 / 实验款
4. A/B 测试建议：每组只改一个变量（如只换开头词）
5. 用户选定后，用 article_write 把标题写回文章项目
