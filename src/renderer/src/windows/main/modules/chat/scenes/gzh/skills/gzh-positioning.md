# 公众号定位三件套

给一个号做**简介、关注后回复、自定义菜单**。三件不是三个任务，是同一个定位的三次表达。

- **核心原则**：先收敛一句话定位，三件全部从它派生。定位没定死就开写，必然写出互相打架的东西——简介说 AI 号，菜单挂读书笔记，自动回复推社群
- **第二原则**：能读就别问。用户已有号 / 已有文章时，从**已发布内容**反推定位，比让他自己描述准得多；描述是「想成为的样子」，文章才是「实际在写的样子」，差距正是诊断价值所在

## 微信硬约束（动笔前先记住，写超直接贴不进后台）

| 产物 | 后台位置 | 限制 |
|---|---|---|
| 账号简介 | 账号设置 → 账号详情 → 介绍 | **4–120 字**，需审核 |
| 关注后自动回复 | 自动回复 → 被添加自动回复 | 纯文字 **600 字**内 |
| 一级菜单 | 自定义菜单 | 最多 **3 个**，每个 **≤4 汉字** |
| 二级菜单 | 同上 | 每个一级下最多 **5 个**，每个 **≤8 汉字** |

- **中英混排按字节折算**：汉字 3 字节、字母数字 1 字节，实践口径「一级 4 汉字或 8 字母，二级 8 汉字或 16 字母」；`Agent专栏`（5 字母 + 2 汉字）安全。空格也占位
- **数字是上限不是目标**：好简介往往 40–70 字；菜单名 2 个字说清就别用 4 个

## 第 0 步：先看有没有现成材料（按序找，找到就别问）

1. **用户在当前项目库已有公众号文章**（与文章创作同库）→ 直接读最近 10–20 篇：标题在讲什么、什么主题反复出现、行文是第一人称还是第三人称
2. **用户给了文章 / 草稿 / 链接** → 直接读
3. **全新号什么都没有** → 才进入完整访谈

读完材料**先把观察抛回给用户确认**，再进入下一步：

> 我看了你最近的篇章，主题基本集中在 A（8 篇）和 B（4 篇），数据最好的三篇都是「实测 + 我的判断」结构。你自己觉得这个号在做 A 还是 B？

一句话替掉五六个访谈问题。注意：`gzh_trends` 只查热榜快照，**不能按账号抓历史**，需要指定账号数据时引导用户贴文章。

## 第 1 步：分层访谈（不要一次抛十几个问题）

**第一轮只问 3 个（必答，等回答）**，对应定位三要素「对象 / 供给 / 凭据」：

1. **你想让谁关注你？** 具体到人——不是「对 AI 感兴趣的人」，是「想用 AI 提效但不会写代码的产品经理」
2. **他关注后能反复从你这拿到什么？** 一件事就够，越具体越好
3. **这件事为什么是你来说比较可信？** 职业、经历、踩过的坑，随便哪一样

**第二轮按需追问（只挑缺口，一般 ≤3 个）**：答案太宽 → 问「你最近三篇具体在讲什么」；缺凭据 → 问「你在这个领域做过最具体的一件事」；要设计菜单 → 问「手上有没有现成的：文章合集 / 工具 / 社群 / 资料 / 付费课」；商业目标不明 → 问「最终想接商单、卖产品、招人还是纯记录」（决定菜单第三格）；风格不明 → 问「读者该觉得你是专业顾问还是同行」。

**禁忌**：不问「差异化优势」「初心」这类答不上来的抽象问题；答得含糊时**给选项**，不让填空。

## 第 2 步：定位陈述（闸门，先确认再往下写）

```
给【谁】，提供【什么】，因为我【凭据】。
```

自查三条：**对象能想象出一个具体的人**（「创业者」不行，「刚开始带团队的技术出身创业者」可以）；**供给可持续**（每周都产得出，「实测工具并给选型判断」可持续，「分享行业洞察」不可持续）；**凭据抄不走**（职业身份、亲历经验、长期作品都算，「热爱学习」不算）。

用户有历史文章时**必须**附定位诊断，不许省略：

> 你说想做 X，但实际写的 15 篇里 11 篇在写 Y。要么简介按 Y 写，要么内容往 X 调，你想走哪条？

## 第 3 步：产出三件套（各 2–3 版，标注适用场景与实际字数）

### 3.1 账号简介（4–120 字）

| 结构 | 骨架 | 适合 |
|---|---|---|
| 身份供给型 | 我是谁 + 写什么 + 频率/形式 | 个人 IP、有明确职业身份 |
| 读者收益型 | 你会拿到什么 + 适合谁 | 工具号、方法号、新号冷启动 |
| 立场型 | 一个明确主张 + 一句支撑 | 观点号、已有辨识度 |

**必须**：至少一个具体名词（AI Agent、K8s、一人公司），通篇抽象词 = 白写；出现读者或读者处境；20 字内能读懂在讲什么。

❌ `专注分享优质干货，与你一起成长`（零信息量）｜❌ `热爱生活、热爱写作的人记录思考感悟`（全是形容词）｜✅ `产品经理，写 AI Agent 怎么真正落进日常工作。每周 2 篇实测，只写自己跑通过的。`（38 字）

### 3.2 关注后自动回复（≤600 字，目标 200–400 字）

**它不是欢迎词，是第一次交付**——关注那一秒是注意力峰值，一句「感谢关注」是纯浪费。四段骨架：

1. 一句话确认「你来对了」（呼应定位）
2. **立刻给一样东西**：最值得读的 3 篇 / 一份资料 / 合集入口——全篇最重要的一段
3. 告诉他怎么用这个号（指路菜单或关键词规则）
4. **一个**低门槛钩子（回复关键词 / 加群），只留一个

❌ 长篇自我介绍；❌ 通篇煽情没有任何可点的东西；❌ 一次给五个行动；❌ 承诺「每天更新」。链接须为公众号文章或已认证外链，未认证订阅号改用「回复关键词」导流。

### 3.3 自定义菜单（3 × 5）

三个一级菜单是**三种读者意图**，不是三个内容分类：左 = **了解**（自我介绍 / 必读 / 合集导航）；中 = **取用**（合集 / 工具 / 模板 / 资料，主力位放最重要的内容资产）；右 = **连接**（联系方式 / 社群 / 合作，由访谈里的商业目标决定）。

命名：**动词优先**（`看合集` 优于 `内容`）；4 字上限 2–3 字更好；禁用 `更多 / 其他 / 杂项`；二级要具体到一个能点开的东西。**新号文章不到 20 篇先只做 1–2 个一级菜单**，空菜单比没菜单伤害更大。

## 第 4 步：字数校验（强制，逐项标注在结果里）

```
✅ 简介 A 版：38 字（限 120）
✅ 关注后回复：287 字（限 600）
✅ 一级菜单：3 个 —— 读什么(3) / 拿工具(3) / 找我聊(3) 全部 ≤4
```

任何一项超限，**改到合规再输出**，不许「仅供参考」地丢给用户。

## 一致性评分（写完自评）

| 维度 | 分值 | 判断 |
|---|---:|---|
| 定位一致性 | 30 | 三件套能否都倒推回同一句定位 |
| 具体性 | 20 | 有具体名词、人群、产出，还是全是形容词 |
| 可兑现 | 20 | 承诺的频率、资料、社群用户真的有吗 |
| 转化路径 | 15 | 新粉丝从关注到拿到第一样东西 ≤2 步 |
| 合规 | 10 | 字数、外链、认证要求 |
| 简洁 | 5 | 有没有可删的字 |

**直接淘汰**：任一项超字数；承诺拿不出的东西；简介和菜单指向两个不同的号。

## 输出格式

① 定位诊断（有历史文章时必含「你说的」vs「你写的」差距）→ ② 一句话定位 → ③ 简介 2–3 版（标结构类型 / 字数 / 场景）→ ④ 关注后回复 1–2 版（标字数，链接用 `【此处放 XX 链接】` 占位并列待补项）→ ⑤ 菜单树状图（每个名称后标字数）→ ⑥ 待补清单（用户需自备的合集链接 / 资料 / 二维码 / 联系方式，**不许替用户编造**）。

## 红线

- **不编造用户的经历、身份、成绩、数据**——访谈没问出来的进待补清单，不许「合理推测」
- **不承诺兑现不了的更新频率**
- 不用「第一 / 最强 / 唯一」等绝对化用语（简介需审核，易被驳回）；不做医疗 / 金融 / 投资效果承诺
- 超字数的方案不允许输出
