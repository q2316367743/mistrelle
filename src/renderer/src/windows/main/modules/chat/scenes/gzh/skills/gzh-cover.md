# 公众号封面

核心知识点：**封面会被裁两次**——消息列表显示完整 2.35:1，分享到朋友圈只抓**正中央 1:1**（1175×500 画布上 x 337–837 的中央区域）。中央放不下核心信息 = 分享出去就是废图。

## 工作流

### 1. 定标题文案

- 封面标题 6–14 字、最多 2 行，先圈出**核心词组**（分享后必须还能看清的那几个字）
- 与文章标题呼应但不重复：封面是情绪钩子，标题是信息承诺

### 2. 选安全区策略

- **策略 A 全居中**：所有元素落在中央 1:1 内，最安全，视觉略保守
- **策略 B 核心词居中（默认）**：核心词组钉在中央，装饰元素可外溢到两翼
- **策略 C 图文分离**：左字右图等经典构图——必须主动提醒用户「分享到朋友圈两翼会被裁掉」

### 3. 生成封面

用 `design_draw(prompt, size)` 在画布绘制（生图型子 Agent 亦可），提示词配方：

```
[风格前缀] + [主体内容] + [构图与安全区约束] + [中文文字指令] + [排除项]
```

- **构图约束必写**：`2.35:1 横版封面，核心文字位于画面正中央 1:1 区域内，两翼仅放装饰性元素`
- 风格前缀示例：`扁平插画风格，低饱和度，大面积留白` / `杂志封面排版，大字标题，强对比` / `3D 质感，柔和光影`
- 文字指令明确字体层级：`主标题「XX」大号加粗，副标题「XX」小号`
- 排除项：`无水印，无英文乱码，文字清晰可读，边缘不留白边`

一次生成一个变体，让用户看完再出下一版；命名 cover-01 / cover-02，**不静默覆盖**。

### 4. 自检（两道都不能跳）

1. **机器自检**：口述核对——画布是否 2.35:1；核心文字是否全部落在中央 1:1（x 337–837）；文字是否 ≤2 行
2. **提醒用户肉眼复查**：让用户把封面图分享到朋友圈预览一次，「分享预览读不通，就是不合格」

### 5. 落盘

封面图存入文章 assets 目录，用 article_write 登记到文章封面字段，告知用户路径。
