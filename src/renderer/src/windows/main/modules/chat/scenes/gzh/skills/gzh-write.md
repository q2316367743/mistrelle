# 公众号长文写作

长文（1500–4000 字）的完整方法论；先诊断现状，再选路推进。短文（≤1000 字）走 `gzh-short` skill。

## 第 0 步：先问「你手上现在有什么？」

第一轮对话先弄清用户处境，按现状路由，不要上来就写：

1. **只有想法** → 访谈式：一次只问一个问题，追问往具体走（谁遇到、什么事、结果如何），攒够细节再动笔
2. **有大纲** → 大纲式：逐节检查大纲， **每节必须带字数配额**，必须有「边界 / 反面」一节，缺什么补什么
3. **写到一半卡住** → 续写式：先诊断卡点——A 大纲没想清（回头补大纲）/ B 缺材料（找素材）/ C 选题立不住（诚实劝退，别硬续）
4. **一堆素材没主线** → 素材整合式：先压缩每份素材到三句话 → 找贯穿主线 → **舍得删**，与主线无关的素材果断丢
5. **有话题没角度** → 破题式：给 5–8 个切入角度，只留「只有你能写」的那个
6. **有完整稿但不满意** → 重写式：先出病灶清单（哪几段什么问题），定点手术， **禁止「整体润色」**

## 公众号体裁五约束（硬性）

- **开头几句可独立成摘要**：不看标题也知道文章讲什么
- **单段 ≤90 字**：手机上约 4 行，超了就拆
- **全文 >2000 字必须分小节**：用 `##` 二级标题，小标题说人话不玩梗
- **读者是订阅者**：默认读者关注了你，背景知识点到为止，不用从头科普
- **结尾只给一个动作**：在看 / 留言 / 试一下，选一个，不堆号召

## AI 腔黑名单（出现即删）

- 套话：本质上、说白了、换句话说、综上、在这个时代、众所周知、无疑、毋庸置疑
- 句式：「不是 X，而是 Y」全文限 1 次；三段排比堆砌直接砍
- 自问自答是合法节奏工具，但 **自问后必须给具体回答**，不许「答案是……」糊弄
- 数字造假零容忍：没有出处的数据宁可不写，标注「待核实」

## 产出与落盘约定

- 成稿写入当前文章项目（article_write），标题用文章标题，正文纯 Markdown
- 结构：标题层级 / 列表 / 引用块组织内容；引用他人观点用 `>` 引用块
- 写完告知用户：字数、小节数、是否建议配图或分页
- 用户说「用我的风格」时，以个性化设定（WRITE.md）为最高优先级文风约束

## 输出前自检

逐项核对：开头独立成摘要？每段 ≤90 字？>2000 字分了小节？结尾只有一个动作？黑名单词清零？例子有细节没编造？——任何一项不过，改完再交付。
