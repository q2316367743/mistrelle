# 公众号配图（逻辑图与图表）

给文章配结构化插图：逻辑关系图 / 数据图表。两条路线，先选路再动手：

- **SVG HTML 路线**：矢量、文字精确、可后期改——结构复杂 / 文字多时用
- **生图路线**：`design_draw(prompt, size)` 直出 PNG——示意图 / 氛围图 / 快速出图时用

## 路线一：SVG HTML

### 1. 判断关系类型

六选一：**递进**（一步步深入）· **流程**（单向顺序）· **循环**（闭环往复）· **层次**（总分 / 包含）· **对比**（两栏对峙）· **矩阵**（双维四象限）

### 2. 概念抽象

- 每个节点 ≤15 字，超了就拆或提炼
- 一篇文章拆多段内容时，生成多个 `diagram-card`（一张图一个论点，不贪多）

### 3. 产出

- 单文件 HTML：内嵌 CSS + 内联 SVG + viewBox `0 0 800 500`（宽高比 ≈ 公众号正文图 900×383 以上任意比例皆可，推荐 16:9 或 21:9 画布类）
- 深浅双主题可用 CSS 变量双套色板；线条用箭头标注方向；节点圆角矩形、字号 ≥14
- 文件写入文章 assets 目录，文件名语义化（如 `flow-compare.html`）
- 告知用户：浏览器打开可预览，需要 PNG 时截图或告知你转存

## 路线二：design_draw 生图

提示词骨架：

```
[图表类型] + [风格前缀] + [节点与关系描述] + [中文文字指令] + [排除项]
```

- 图表类型 10 类：流程图 · 架构图 · 对比图 · 时间线 · SWOT · 思维导图 · 漏斗图 · 循环图 · 金字塔 · 矩阵图
- 风格前缀 6 种（按内容推荐）：blueprint（蓝图工程风，默认）/ notion（简洁文档风）/ sketch-notes（手绘笔记风）/ corporate（商务演示风）/ dark-atmospheric（深色氛围）/ watercolor（水彩插画风）
- 构图约束：`16:9，2K 分辨率，节点文字为简体中文，清晰可读`
- 排除项：`无乱码英文，无水印，元素不重叠`

## 收尾约定

- 配图插入正文：`![描述](路径)` 独立成段
- 每张图给一句话图注建议（放在图下方，帮读者 3 秒看懂）
- 同一篇配图 ≥3 张时提醒：公众号正文图太多会稀释完读率，建议 1–2 张核心图
