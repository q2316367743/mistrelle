# 海报设计指南（poster）

> 电影海报 / 活动海报 / 音乐海报 / 通用宣传海报。海报是"一眼抓住注意力"的艺术，
> 主视觉、大标题、留白与配色决定成败。

## 1. 画布尺寸

| 类型 | 比例 | 尺寸 |
|---|---|---|
| 通用 / 竖版海报 | 3:4 | 1080 × 1440 |
| 电影 / 路演海报 | 2:3 | 1242 × 1863 |
| 横版活动海报 | 16:9 | 1920 × 1080 |
| 音乐 / 巡演海报 | 3:4 或 1:1 | 1080 × 1440 / 1080 × 1080 |

## 2. 构图

- **一个视觉焦点**：主视觉（人物 / 剪影 / 图形 / 大标题即图形）是绝对主角，其余元素服务它。
- 常用范式：主视觉居中 + 四周留白；或左右分屏（左文案右主视觉）；或三分法 / 对角线动感排布。
- **大标题就是海报的灵魂**：字号 80~160px，通常占画面 1/3~1/2 高度，宁可大也不要小气。
- 留出负空间；元素不要堆满全版。

## 3. 文字排版

- 主标题：粗字重（700~900）+ 紧字距，可全大写 / 斜体 / 描边字增加气质。
- 副信息：日期、地点、主办方、主创名单，小字号（16~32px）放标题下方或底部。
- 信息层级：主标题 → 副标题/类型 → 时间地点 → 落款，严格按层级缩小字号。
- 文字压图必须保证可读（半透明遮罩 / 阴影 / 描边）。

## 4. 色彩

- 电影海报常用**深色基底 + 单一强调色**（如深蓝黑 + 暖黄），氛围感强。
- 活动海报可用明快对比色，但 ≤1 个强调色，避免花。
- 全页只用一套色板；禁用纯黑 `#000000`、禁紫蓝 AI 渐变。

## 5. 主视觉来源

- 品牌海报的 logo：用 `website_logo(url)` 取官网真实 logo（返回本地路径填 imageUrl），禁止自己画近似 logo。
- 真实图片（人物 / 场景）：用 image 操作 `web` 类型（真实 URL）或 `stock`（picsum）或先占位再换图。
- 无图时：用几何剪影（椭圆 / 矩形 / 路径组合）、渐变背景、或让大标题本身成为主视觉。
- 禁止随手编随机图片 URL；真实素材经工具落盘沙盒后使用。

## 6. 自检清单

- [ ] 只有一个视觉焦点？
- [ ] 主标题够大、层级分明、可读？
- [ ] 时间 / 地点 / 主办方信息齐全（活动类）？
- [ ] 有足够留白？
- [ ] 配色克制、与主题情绪匹配？
