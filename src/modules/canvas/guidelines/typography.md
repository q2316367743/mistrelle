# 字体排版指南（typography）

> 平面设计是"文字排版的艺术"。标题怎么选字体、怎么排字距行距，
> 决定作品是"高级杂志"还是"廉价 PPT"。

> **指定字体的正确姿势**：动手前先 `font_list` 查本机可用字体（系统 + 资源库），从返回里选
> `fontFamily`；模型臆想的名字（如 Outfit / 思源宋体）本机可能没有，会回退默认字体。
> 用户提供了未安装的字体文件时，先 `font_register` 入库再用其 name。

## 1. 标题（Display）

- 标题是作品的灵魂，选有性格的字体，**不要默认 Inter / 系统黑体**。
- 常用方向（先 `font_list` 确认本机是否有）：
  - 现代科技感：`Geist`、`Outfit`、`Satoshi`、`Space Grotesk`（克制使用）
  - 中文文艺感：`思源宋体`（衬线）、`站酷酷黑`、`优设标题黑`、`霞鹜文楷`
  - 极简无衬线：`Noto Sans SC` 加 `fontWeight: 700/900` + 紧字距
- 大标题**字距收紧**（letterSpacing 负值或小正值），正文字距放松。
- 大标题可通过 `italic` 斜体、`textCase: 'upper'` 全大写增加气质。

## 2. 层级

- 三级体系：主标题 → 副标题 / 区块标题 → 正文 / 注脚。
- 用**字重 + 字号 + 颜色**三层同时拉开层级，不要只靠字号。
  - 主标题：大字号 + 粗字重（700~900）+ 高对比颜色
  - 副标题：中等字号 + 常规字重（400~500）+ 灰色
  - 正文：小字号 + 浅灰 + 高行高
- 同屏字体**不超过 2 个家族**（如 1 个展示字体 + 1 个正文），避免花。

## 3. 字号 / 字距 / 行距参考

- 主标题：海报 64~120px；正文区标题 24~40px。
- 正文：14~18px；注脚 10~12px。
- 行高：正文 1.4~1.6；多行标题 1.1~1.2（紧凑更高级）。
- 字距：大标题收紧（-2~2px），正文 0，小字 / 全大写适当放松（2~4px）。

## 4. 文字效果（克制使用）

- **描边文字**（stroke + strokeWidth）：科技感 / 运动海报常用，适合短词。
- **渐变文字**（text 的 fill 用渐变对象）：只在小面积（关键词 / 强调词）用，**禁大标题整段渐变**。
- **文字背景色块**：给标题垫一个色块 / 色条，复古海报感。
- **斜体 / 全大写**：整句全大写配宽松字距很有编辑感。

## 5. 可读性

- 文字**必须设置可见颜色**（fill），否则默认透明不可见。
- 深色背景上用浅色文字，浅色背景上用深色文字，保证对比（WCAG AA）。
- 文字压在图上时：给图加半透明遮罩，或给文字加阴影 / 描边保证可读。
- 文案别太长：海报标题 6~12 字、副标题一句话、正文 ≤ 60 字符每行。

## 6. 中英混排

- 中文 + 英文搭配：中文正文用思源 / 苹方系，英文强调词用展示字体形成对比。
- 数字 / 数据用等宽字体（monospace）更有科技感（仪表盘、数据海报）。
- 中文不斜体（斜体只用于拉丁字母）；中文全大写无意义，用加粗 + 紧字距代替。
