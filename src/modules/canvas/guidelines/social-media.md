# 社交媒体配图设计指南（social-media）

> 公众号封面 / 小红书配图 / 头图 Banner。核心是**小屏可读 + 手机端传播**：
> 缩略图时代，文字要大、视觉要强、信息要一眼懂。

## 1. 画布尺寸

| 类型 | 比例 | 尺寸 | 要点 |
|---|---|---|---|
| 公众号封面 | 2.35:1 | 900 × 383 | 标题区在右侧约 1/3（微信会遮挡左侧） |
| 公众号次图 / 头图 | 1:1 | 900 × 900 | 缩略图圆形裁切，中心内容安全 |
| 小红书竖版配图 | 3:4 | 1242 × 1660 | 正文与封面分离，封面文字少而大 |
| 横版 Banner | 16:9 | 1920 × 1080 | 标题 + 副标题 + CTA |

## 2. 公众号封面要点

- 微信封面**左侧会被标题文案遮挡**：主视觉与关键文字放右侧，或整图留足够安全边距。
- 大标题（≥ 72px）直接上图，缩略图下也清晰可读。
- 系列感：同账号封面用统一版式 / 色调，形成识别度。

## 3. 小红书配图要点

- 封面图文字 ≤ 12 字，**大而少**；信息正文放后续图片。
- 常用手法：上 1/3 放吸引眼球的视觉 + 大字标题，下 2/3 放内容 / 说明。
- 竖版长图：分块清晰，避免连续文字墙；可用数字 / 图标 / 分点提升可读性。
- 配色明快、对比强（信息流中跳出来）。

## 4. 构图与排版

- 手机端阅读距离远：正文 ≥ 24px，标题 ≥ 64px，确保小屏清楚。
- 一个封面只表达一个核心信息（一个钩子）。
- 留白与对齐：缩略图下，干净的画面比复杂的更吸引点击。

## 5. 自检清单

- [ ] 关键文字是否在安全区（公众号避开左侧）？
- [ ] 标题大而少，缩略图下可读？
- [ ] 一个封面只有一个核心信息？
- [ ] 配色明快、系列感统一？
