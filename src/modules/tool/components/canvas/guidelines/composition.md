# 构图指南（composition）

> 平面设计（海报 / 封面 / 配图）的构图法则。构图是"设计创意"的核心能力，
> 好的构图让画面有焦点、有动线、有呼吸感；坏的构图堆砌元素、平铺直叙。

## 1. 一个视觉焦点

- **每张作品只有一个主视觉**（hero），其余元素服务它。
- 视觉重量必须反映重要度：主视觉 > 次级信息 > 装饰。
- 避免"所有元素同等权重"的平铺；避免多个焦点互相打架。

## 2. 负空间（留白）

- 留白不是浪费，是设计的一部分。高级感的来源之一就是敢于留白。
- 元素间留出呼吸：标题与正文、图形与文字、区块与区块。
- 宁可少放一个元素，也不要挤满画面。

## 3. 构图范式（按需选，不要每次都居中）

| 范式       | 适用               | 要点                                       |
|------------|--------------------|--------------------------------------------|
| 居中       | 庄重 / 极简 / 封面 | 主视觉居中，四周大量留白                   |
| 三分法     | 摄影类海报         | 主体放画面 1/3 处，视线沿三分线            |
| 左右分屏   | 文案 + 图像        | 左文右图 / 左图右文，各 50% 或 60/40       |
| 对角线     | 动感海报           | 元素沿对角线排布，制造张力                 |
| 满版出血   | 视觉冲击           | 图片铺满全版，文字叠在图上（需保证可读性） |
| Bento 瓦片 | 信息整合           | 不对称网格，尺寸各异                       |
| 对称镜像   | 正式感             | 上下或左右镜像，元素精确对齐               |

## 4. 视觉动线

- 引导视线：先看主视觉 → 再看标题 → 再扫正文 → 最后是 CTA / 落款。
- 动线靠大小、明暗、颜色对比引导，不要靠箭头。
- 从上到下 / 从左到右的阅读顺序，重要信息在上。

## 5. 层级与比例

- 三级文字层级：主标题（最大，最重）→ 副标题 / 区块标题 → 正文 / 注脚。
- 层级落差要明显：主标题与正文的号差建议 2.5~4 倍。
- 图形元素大小与文字层级呼应，不要出现"次要装饰比主标题还大"。

## 6. 对齐

- 对齐是"精致感"的地基：同类元素严格对齐（左对齐 / 居中 / 基线对齐）。
- **区域内对齐交给布局引擎**：同一区域的元素用 `group` + `layout`（gap / 两轴对齐）自动排齐，不要手算子元素坐标；区域内 ≥2
  个元素必须先分组（见 operations 的「区域分组原则」）。
- 间距系统化：group 的 `gap` / `padding` 用 8 / 12 / 16 / 24 / 32 / 48，不要随手乱填。
- 网格思维：把画布分成列，顶层区块 / 原子元素落在网格线上。

## 7. 常用画布尺寸（按用途）

| 用途                | 比例   | 尺寸（逻辑像素） |
|---------------------|--------|------------------|
| 通用海报            | 3:4    | 1080 × 1440      |
| 电影 / 竖向海报     | 2:3    | 1242 × 1863      |
| 专辑封面            | 1:1    | 1000 × 1000      |
| 书籍封面            | 3:4    | 900 × 1200       |
| 公众号封面          | 2.35:1 | 900 × 383        |
| 小红书 / 竖版配图   | 3:4    | 1242 × 1660      |
| 读书笔记 / 知识卡片 | 4:3    | 800 × 600        |
| 横版头图 / Banner   | 16:9   | 1920 × 1080      |

## 8. 构图自检清单

- [ ] 只有一个视觉焦点？
- [ ] 有足够的负空间？
- [ ] 主视觉与标题层级分明？
- [ ] 同类元素严格对齐？
- [ ] 配色克制（≤1 强调色）？
- [ ] 如果去掉装饰，主信息还完整？
