# 书籍封面设计指南（book-cover）

> 实体书 / 电子书封面。封面是"书架上的三秒竞争"：远看有辨识度，近看有细节。
> 书名是绝对主角，字体气质决定书籍调性。

## 1. 画布尺寸

| 类型 | 比例 | 尺寸 |
|---|---|---|
| 竖版封面（正面） | 2:3 | 900 × 1350 |
| 标准开本 | 3:4 | 900 × 1200 |
| 横版（画册 / 图录） | 4:3 | 1200 × 900 |
| 含书脊三联 | 约 11:16 | 例如 前端 900 + 书脊 80 + 封底 900 |

## 2. 构图

- **书名是绝对主角**：字号大（≥ 96px），位置醒目（上部 / 中部 / 满版均可），宁大勿小。
- 封面元素克制：书名 + 作者名 + 出版社 + 一个主视觉（图形 / 图案 / 留白）。
- 常见范式：居中书名 + 四周留白（文艺）；满版图案 + 小书名（艺术）；几何图形组合（设计感）。
- 对称与留白是封面的高级感来源，避免堆砌。

## 3. 文字排版

- **字体随书籍气质**：
  - 文学 / 散文 / 社科 → 衬线（思源宋体、衬线展示字体），优雅从容
  - 科技 / 商业 / 工具书 → 无衬线（Outfit / 思源黑体）+ 紧字距，理性
  - 悬疑 / 惊悚 → 大字号 + 克制配色，可配撕裂 / 阴影元素
- 层级：书名（最大）→ 副标题 / 系列名 → 作者名 → 出版社名（最小，常放底部）。
- 书名可配竖排（中文纵向排版更有书籍感）。

## 4. 色彩

- 配色与内容调性一致：文艺类低饱和（米白 / 墨绿 / 砖红），科技类冷灰 + 单一强调色。
- 经典手法：**单色背景 + 白色/深色书名**，永不过时。
- 禁止：纯黑 `#000000`、花哨多色、紫蓝 AI 渐变。

## 5. 主视觉来源

- 图案化视觉（几何 / 渐变 / 线条）比写实图片更耐看，适合封面。
- 用 image 操作 `stock` 或占位；写实封面建议给图片留够面积。

## 6. 自检清单

- [ ] 书名是视觉第一眼？
- [ ] 字体气质与书籍题材匹配？
- [ ] 作者名与出版社名位置规范？
- [ ] 远看（缩略图）能辨识标题与色调？
- [ ] 配色克制、调性统一？
